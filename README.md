## ✨ Features

### Public Site (Customer Side)
- 🔍 Car listings with search, filter, sort & pagination — live from Firestore
- 🛒 Buy or Rent vehicles — dual pricing with live total calculation
- 🚘 Test-drive booking system
- 💰 EMI / Finance calculator
- ❤️ Wishlist functionality
- ⭐ Reviews — rate individual cars or leave an overall showroom review
- 👤 Customer dashboard
- 🔐 Firebase Authentication (signup/login)

### Admin Panel
- 📊 Dashboard with live analytics — revenue trend (Buy vs Rent), booking status, low-stock alerts
- 🚗 Manage Cars — full CRUD with multi-image gallery upload and brand/category dropdowns
- 🏷️ Manage Brands & Categories
- 🧰 Manage Services & Service Packages
- 👥 Manage Customers, Staff & Users
- 📅 Manage Bookings — status workflow (Pending → Confirmed → Completed)
- ⭐ Manage Reviews & Blogs
- 🔔 Notifications
- ⚙️ Showroom Settings — contact info, map, social links
- 🔒 Role-based access control — only Admin accounts can access `/admin/*` routes
